## Overview
This project presents a comprehensive analysis of COVID-19 data using R programming. The aim was to extract insights and trends from raw datasets and translate them into meaningful, actionable intelligence through data cleaning, transformation, and visualization.

## Tools Used
- R Programming
- Tidyverse (dplyr, ggplot2, tidyr)
- R Markdown
- MS Word (for final report)

## Project Highlights
- Cleaned and transformed COVID-19 datasets to identify global trends.
- Used visualizations to reveal patterns in infection rates, recoveries, and fatalities.
- Interpreted results to produce actionable recommendations.
